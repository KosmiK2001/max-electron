# max-electron

Нативный десктоп-клиент мессенджера **MAX** для Linux — чистая Electron-обёртка
над официальным веб-клиентом [web.max.ru](https://web.max.ru/).

## Зачем, если есть официальный deb

Официальный клиент MAX (26.35.x) — проприетарный Qt6/QML-бинарь, в котором:

- **трей не работает вообще**: приложение использует `QtQuick.Labs.Platform`
  SystemTrayIcon, который требует `QApplication`, а клиент создаёт
  `QGuiApplication`; в бандловом xcb-плагине нет ни StatusNotifier, ни XEmbed;
- служебные окна процесса `max-service` лезут в панель задач и украшаются
  рамкой (см. репозиторий-двойник: патчи-костыли через внешнего watcher'а);
- **звонки** требуют отдельного 92-МБ `max-service` со своим устаревшим
  бандлом системных библиотек (libsystemd/freetype/harfbuzz), из-за чего он
  падал на загрузке даже на свежих дистрибутивах;
- размер пакета ~2.2 ГБ после установки.

Здесь — ровно то, за что обычно ставят WhatsApp Desktop / Viber через
неофициальные обёртки: тот же веб-клиент, но с нормальным треем (SNI),
уведомлениями, бейджем непрочитанных, close-to-tray, прокси-настройкой и
памятью геометрии окна.

## Возможности

- трей (левый клик — показать/спрятать, правый — меню настроек);
- прокрутка чата, которой нет в веб-версии: `PageUp`/`PageDown` листают
  страницу видимого чата, кнопки «↑/↓» в титлбаре шагают по одному
  сообщению (реализация — `app/assets/chat-scroller.js`, структура DOM
  вычитана из бандла web.max.ru; клавиша не перехватывается, если фокус
  в модалке, панели стикеров или переполненном поле ввода; приглушается,
  когда открытый список сообщений не найден);
- счётчик непрочитанных: оверлей на иконке в таскбаре, смена иконки трея,
  мигание рамки (отключается «тихим режимом»);
- системные уведомления (разрешение выдаёт main-процесс, веб-страница
  не получает ни `require`, ни `ipcRenderer`: `contextIsolation` + `sandbox`);
- закрытие окна → трей (отключается в меню);
- запуск свёрнутым; память позиции/размера/максимизации окна;
- единственный экземпляр (второй запуск поднимает существующее окно);
- прокси явной строкой в `config.json` (`http://` или `socks5://`);
- навигация только по доверенным доменам (`*.max.ru`, `*.vk.ru`, `*.vk.com`),
  всё остальное — во внешний браузер;
- десктопный Chrome-UA (иначе web.max.ru предлагает установить приложение).

Без внешних npm-зависимостей: только встроенные модули Electron, весь код
в `app/` читается и аудируется целиком.

## Тесты

Логика прокрутки чата проверяется стендом без Electron и без сети:

```sh
node test/chat-scroller-test.js   # выход 0 = всё зелёно
```

Стенд поднимает минимальный фейковый DOM с геометрией (вложенность
`scrollListScrollable > … > [data-index] > messageWrapper`, как в реальном
бандле) и прогоняет по нему настоящий инжект: выбор списка, шаг по
сообщениям, страничную прокрутку, приоритет модалки, все охранки клавиатуры.
Остальное (трей, титлбар, уведомления) требует живого Electron — см.
`## Запуск из исходников`.

## Запуск из исходников

```sh
# нужен только рантайм Electron (>=44), npm-установка не требуется
wget https://github.com/electron/electron/releases/download/v44.9.0/electron-v44.9.0-linux-x64.zip
unzip electron-v44.9.0-linux-x64.zip -d electron-runtime
./electron-runtime/electron ./app
```

Конфиг: `~/.config/max-electron/config.json` (создаётся при первом запуске).

## Установка в Gentoo

ebuild `net-im/max-electron` в оверлее
[kosmik2001-overlay](https://github.com/KosmiK2001/kosmik2001-overlay):
качает этот tarball + Electron-рантайм, кладёт в `/opt/max-electron`,
создаёт `/usr/bin/max-electron`.
